# manga_analysis
An assignment on analysis of API calls from MangaDex based on python and streamlit

## Repository structure

- `README.md`
- `requirements.txt`
- `app.py` (Streamlit application)
- `etl.py` (ETL entry point)
- `data/raw/` (raw API extracts or cached raw data)
- `data/processed/` (processed analytical outputs)
- `ai_transcript/` (AI conversation transcript artifacts)
- `src/` (supporting modules)
- `tests/` (tests)
